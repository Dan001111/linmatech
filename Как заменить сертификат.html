Замена дилерского сертификата

На сайте под управлением WordPress сертификаты заводятся в админке — загрузили скан, заполнили поля, опубликовали. Раздел «Файлами напрямую» ниже нужен только для статической версии сайта, которая лежит в репозитории.

Коротко

Сертификаты → Добавить в левом меню админки. Скан прикладывается как изображение записи, PDF выбирается кнопкой, миниатюру WordPress делает сам. Ни файлового менеджера, ни правки файлов не нужно.

Через админку

1

Открыть раздел

В левом меню админки — пункт «Сертификаты», между «Страницами» и «Комментариями». Кнопка «Добавить» вверху.

2

Заполнить карточку

ПолеЧто писать
Название Марка — Daikin, VENTZ. Крупная подпись под плиткой. Можно несколько через запятую.
Тип документа Формулировка из документа: «Официальный дилер», «Партнёр».
Кем выдан Организация, выдавшая сертификат.
Срок действия словами Как в документе: «до 31 декабря 2027». Если срока нет — «выдан 14 июля 2026».
Дата окончания Только чтобы сайт сам повесил плашку «Срок истёк». Нет срока — оставьте пустым.
Документ PDF Кнопка «Выбрать файл» — загружаете PDF в медиатеку.
Альбомная ориентация Галочка только для горизонтальных документов.
Скан сертификата Блок справа. Загрузите картинку целиком — размеры WordPress сделает сам.
Порядок Блок «Атрибуты» справа. Меньше число — выше на странице.
Важно

Скан нужен один, крупный — от 1200 px по длинной стороне. Готовить вторую уменьшенную копию, как раньше, не нужно.

3

Опубликовать и посмотреть

Кнопка «Опубликовать», затем откройте страницу «Дилерские сертификаты» на сайте. Плитка появится сразу — ничего заливать и обновлять принудительно не нужно.

Чтобы заменить сертификат на продлённый: откройте его в списке, замените скан и PDF, поправьте две даты, сохраните.

Файлами напрямую

Этот путь нужен только для статической версии — той, что лежит в репозитории и открывается двойным щелчком по index.html. На сайте WordPress им пользоваться не надо.

Имя латиницей refcool
assets/img/certificates/refcool.jpg 1200 px
assets/img/certificates/refcool-thumb.jpg 560 px
assets/docs/certificates/refcool.pdf документ

Одно имя задаёт все три файла сразу. Оно же пишется в строку описания. Если имена разойдутся хотя бы в одном символе — сертификат не появится или откроется без документа.

Что понадобится

  • PDF нового сертификата
  • Папка сайта на компьютере — Сайт Линма
  • Программа «Ножницы» и Paint — уже есть в Windows
  • Доступ к файлам сайта на хостинге: файловый менеджер reg.ru или FTP

Порядок работы

1

Придумать имя

Короткое слово латиницей, строчными буквами, без пробелов — обычно марка или производитель: refcool, daikin, ventz. Пробелы заменяются дефисом: pk-tech.

Посмотрите в assets/js/certificates.js, какие имена уже заняты — они перечислены в поле slug. Повторяться нельзя.

2

Сделать два изображения из PDF

Нужны два снимка одного и того же документа: крупный для просмотра и маленький для плитки.

  1. Откройте PDF двойным щелчком и увеличьте так, чтобы документ занял экран по высоте целиком.
  2. Нажмите Win + Shift + S и выделите документ — ровно по краям листа, без полей программы.
  3. Откройте Paint, нажмите Ctrl + V.
  4. Меню Изображение → Изменить размер. Переключитесь на Пиксели, галочка «Сохранить пропорции» включена. Поставьте 1200 в длинную сторону: для вертикального документа это высота, для горизонтального — ширина.
  5. Файл → Сохранить как → Изображение JPEG, имя — refcool.jpg.
  6. Нажмите Ctrl + Z, чтобы вернуть исходный размер.
  7. Снова Изменить размер, теперь 560 в длинную сторону. Сохраните как refcool-thumb.jpg.
Важно

Не перепутайте порядок: если сначала уменьшить до 560, а потом растянуть до 1200, крупная версия получится размытой. Уменьшать нужно всегда из исходника.

Быстрее через онлайн-конвертер. Любой сервис «PDF в JPG» даст картинку лучшего качества за полминуты. Эти сертификаты и так выложены на сайте в открытом доступе, так что загружать их на сторонний сервис безопасно.

Но

Это касается только сертификатов. Договоры, соглашения о ценах и карточку организации на онлайн-сервисы не загружайте — они не предназначены для публикации.

3

Разложить файлы по папкам

В папке сайта на компьютере:

ФайлКуда положить
refcool.jpg assets\img\certificates\
refcool-thumb.jpg assets\img\certificates\
refcool.pdf assets\docs\certificates\

PDF переименуйте в то же имя — файл от поставщика может называться как угодно, на сайте он должен стать refcool.pdf.

4

Дописать строку в список

Откройте assets\js\certificates.js Блокнотом и найдите список, который начинается со строки window.LINMA_CERTIFICATES = [. Добавьте туда строку по образцу: 

{ slug: "refcool", brand: "Refcool", issuer: "ООО «Компания»", type: "Официальный дилер", valid: "до 31 декабря 2027", ends: "2027-12-31" },

Место в списке = место на странице. Хотите показать сертификат первым — поставьте строку первой.

Важно

Кавычки только прямые — ", не «ёлочки». Блокнот их не подменяет, а Word подменяет, поэтому редактируйте Блокнотом.

Запятая в конце строки нужна у всех записей, кроме самой последней в списке. Если ставите свою строку в конец — уберите запятую у неё и допишите её предыдущей.

Что писать в каждом поле:

ПолеЧто это
slug Имя из шага 1. Должно совпасть с именами файлов до символа.
brand Торговая марка — крупная подпись под плиткой. Можно несколько через запятую: "LuftMeer, Заслон".
issuer Кто выдал документ, как написано в самом сертификате.
type «Официальный дилер», «Партнёр», «Официальный дистрибьютор» — формулировка из документа.
valid Срок действия человеческими словами. Видно только в окне просмотра.
ends Дата окончания как 2027-12-31 — год, месяц, день. По ней сайт сам повесит плашку «Срок истёк», когда время придёт. Если срок в документе не указан — оставьте пустые кавычки: "".
wide Только для горизонтальных документов — допишите wide: true перед закрывающей скобкой. Такие карточки выводятся отдельной сеткой под вертикальными. Для вертикальных поле не нужно вовсе.
5

Проверить у себя

До заливки на сайт посмотрите, что получилось. В папке сайта лежит serve.ps1 — запустите его двойным щелчком правой кнопкой мыши → «Выполнить с помощью PowerShell», затем откройте в браузере: 

http://localhost:8099/certificates.html

Проверьте три вещи:

  • плитка появилась и картинка на ней видна;
  • по щелчку открывается крупная версия;
  • кнопка со ссылкой на PDF открывает документ.
Готово

Если всё три пункта сошлись — файл заполнен правильно, можно заливать.

6

Сохранить изменения в репозитории

Статическая версия никуда не заливается — она и есть папка на компьютере. Чтобы изменения не потерялись и попали к коллегам, отправьте их на GitHub: 

git add -A
git commit -m "Добавлен сертификат Refcool"
git push
Не нужно

Копировать эти файлы в тему на хостинге не надо. Сайт на WordPress берёт сертификаты из админки, а не из certificates.js — положенные туда файлы просто ничего не изменят.

Если сертификат просто продлили

Когда марка та же, а документ новый, — имя менять не нужно. Работы меньше:

  1. Сделайте два изображения по шагу 2 и положите их вместо старых — имена те же, файлы перезапишутся.
  2. Замените PDF.
  3. В certificates.js у этой записи поправьте только valid и ends на новые даты.
  4. Проверьте по шагу 5 и залейте по шагу 6.

Если не появилось

Что видноПочему
Страница пустая, плиток нет вообще Ошибка в certificates.js — чаще всего пропущенная запятая или кривые кавычки. Скрипт перестаёт читаться целиком, поэтому исчезают все сертификаты, а не один.
Плитка есть, картинки нет Имя файла не совпало с slug. Проверьте регистр и расширение: должно быть .jpg, а не .JPG или .jpeg.
Картинка есть, PDF не открывается Документ не положен в assets/docs/certificates/ или назван иначе.
Плитка вытянулась или обрезалась Документ горизонтальный, а wide: true не проставлено. Или наоборот — проставлено у вертикального.
Правили файлы, а на сайте ничего не изменилось Сайт на WordPress читает сертификаты из админки. Правка файлов меняет только статическую версию. Заводите сертификат через Сертификаты → Добавить.
Откат

Испортили файл и не понимаете что — возьмите рабочую версию certificates.js из репозитория на GitHub и положите обратно. Все прежние состояния сайта там сохранены.

Тем же способом правятся списки брендов, объектов и продукции собственного производства — соседние файлы в assets/js/. Устроены они одинаково, а в начале каждого написано, что означают поля.
